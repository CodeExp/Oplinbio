# AccessConfig

Copie d'[AccessConfig](https://github.com/access42/AccessConfig) d'Access42 (licence MIT, voir `LICENSE.md`),
version du dépôt officiel au commit `1c01cf4` (18/07/2023).

AccessConfig ajoute un bouton « Paramètres d'accessibilité » qui ouvre une fenêtre permettant
à chaque visiteur d'adapter l'affichage : contrastes renforcés ou inversés, police adaptée à la
dyslexie (OpenDyslexic), interlignage, justification du texte et remplacement des images par leur texte.

Documentation : https://accessconfig.a11y.fr
